# 极狐适配合并 DiPlay 0.2.21

合并日期：2026-10-18。上游范围为 `v0.2.21` 发布标签；不额外引入标签之后的 main 改动。

## 保留的极狐功能

- 极狐车型识别与手动配置、1920×720 仪表输出、安全区域与车标位置设置。
- 默认仅导航时显示仪表地图、路口卡片联动、方向盘缩放与已有按键处理。
- HUD 导航转发、有效导航周期重发与连接恢复；没有修改车机 NaviService。
- 导航默认通道 11、Siri 17、媒体 3 及原版自动通道 0 的兼容逻辑。
- 导航有效 PCM 播放完成后约 200 ms 释放极狐导航焦点的修复。
- 媒体同步使用当前 ArcLink/CarLink 传输方案，封面、歌词、媒体控制与来源仲裁继续保留。
- 电话音频模式、原车蓝牙电话共存、定位与麦克风权限处理、车辆数据读取。
- 普通版认证资产保持原路径；原生鉴权仍为独立构建选项，不切换普通版认证。

## 合并处理

- 保留上游音频时钟/缓冲恢复、导航音量衰减、有线重试、热点及诊断更新。
- 合并上游媒体焦点恢复接口，同时保留极狐媒体来源互斥和路由恢复。
- 上游停止仪表流 15 秒释放窗口的逻辑仅保持在原适用车型；极狐仍保留隐藏的解码窗口与缩放目标。新增回归测试，防止重新导航时窗口和按键失联。
- 有线控制通道保留极狐生命周期回调，并接入上游启动看门狗的进度通知。
- 保留极狐跟随主题的背景，同时接入上游可选圆角遮罩功能；不改变现有遮罩设置默认值。
- 新增意大利语中的极狐设置文案，以兼容上游新增语言。
- Siri 实体按键替代方案暂缓，未修改原车按键服务，也未增加新的强制按键映射。
